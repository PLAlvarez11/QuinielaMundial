
Python version : 3.14.4


## crear entorno
```
python -m venv venv
```
## activar
### linux
```
source venv/bin/activate
```
### Windows
```
venv\Scripts\activate
```

## instalar deps
```
pip install -r requirements.txt
```

## migraciones
```
python manage.py migrate
```

## correr servidor
```
python manage.py runserver
```
